# TD-S-curit-Avanc-e
Dépôt travaux pratiques lab du cours Sécurité. Contient les configurations, scripts, ressources utilisés pour l’étude et la mise en œuvre de mécanismes de sécurité réseau (TCP/IP, pare-feu, VPN, etc.). Objectif : fournir un support pratique pour la validation des concepts de sécurité appliqués aux infrastructures informatiques.
